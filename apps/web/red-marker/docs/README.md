Research documentation for audio timbre analysis, spectral matching, and sound design automation. These docs inform the `@barry/music` package and Ableton tooling.

- [timbre-science.md](./timbre-science.md) — The science of timbre perception, how humans hear differences in sound character

### Techniques

- [timbre-transfer.md](./timbre-transfer.md) — Timbre transfer and style transfer approaches (DDSP, SynthCloner, differentiable DSP)
