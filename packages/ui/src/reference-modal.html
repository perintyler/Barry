Native Modal

Native <dialog> modals with size, position, and backdrop variants

Variants

Small Modal

A compact modal with scrim backdrop. Great for confirmations and short messages.

Default Modal

This is the default modal configuration — medium size, centered, with a blur backdrop.

It supports all the standard .modal-body typography styles from the design system.

  • Focus trapping is handled natively by the browser
  • Escape key closes the dialog
  • Click the backdrop to dismiss

Large Modal

A wider modal (680px max) with a gradient backdrop effect. Suitable for forms, detailed content, or media previews.

Section Heading

The large variant provides more horizontal space for complex layouts while maintaining readability.

Blockquotes work too — styled with the design system's orange accent border.

Fullscreen Modal

Takes up the entire viewport. No border-radius, full-width. Ideal for immersive experiences, image galleries, or complex multi-step flows.

Bottom Sheet

Anchored to the bottom of the viewport with top-only border radius. Natural position for mobile action sheets and contextual menus.

Bottom Sheet (Scrim)

Same bottom position but with a simple scrim backdrop — no blur. Lighter visual weight.

Fullscreen Modal

Dialog fills the viewport. The gradient backdrop is a child div — the native ::backdrop is transparent. Content aligns to bottom by default.
