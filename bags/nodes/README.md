# Node registry

Maintains this installation’s node identity, identity directories and linked owners/workers. Peer records are node-owned SQLite data; adding a record alone does not authorize remote execution.

Use Node 26.9 or later and the repository’s frozen pnpm workspace installation. This package is linked within the repository; this documentation does not claim a published SDK or package release.

See the [operating documentation](../../sdk/docs/workflows-runbook.md) for installation and verification.
