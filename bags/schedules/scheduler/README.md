# Scheduler runtime

Runs authored schedules and delegates execution through the configured Barry services. This private service package exports runner helpers; its `start` script is a development entry, not an installation command. Use the installation service manager for persistent operation.

Use Node 26.9 or later and the repository’s frozen pnpm workspace installation. This package is linked within the repository; this documentation does not claim a published SDK or package release.

See the [operating documentation](../README.md) for installation and verification.
