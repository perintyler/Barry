# Sessions API

The private HTTP and WebSocket composition root serves sessions and coordinates identity, scheduler, action and recording services. `pnpm start` runs its source entry for development; persistent service configuration belongs to the installation. Session access requires authentication and current ownership checks.

Use Node 26.9 or later and the repository’s frozen pnpm workspace installation. This package is linked within the repository; this documentation does not claim a published SDK or package release.

See the [operating documentation](../README.md) for installation and verification.
