# Identities service

This private composition root installs the vendor catalog and serves identity operations. Keep vendor selection in this service rather than adding vendor imports to the identity bag. Service lifecycle and secret references are managed by the installation.

Use Node 26.9 or later and the repository’s frozen pnpm workspace installation. This package is linked within the repository; this documentation does not claim a published SDK or package release.

See the [operating documentation](../README.md) for installation and verification.
